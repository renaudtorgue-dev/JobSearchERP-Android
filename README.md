# JobSearch ERP Android

Application Android native pour JobSearch CRM ERP 3.7+.

## Pré-requis côté WordPress
1. Installer et activer `jobsearch-crm-erp-3.7-mobile-api.zip`.
2. WordPress > Utilisateurs > Profil > Mots de passe d’application.
3. Créer un mot de passe d’application nommé `JobSearch Android`.

## Premier lancement
Saisir :
- URL HTTPS du site WordPress ;
- identifiant WordPress ;
- mot de passe d’application (pas le mot de passe principal).

## Fonctions v1
- annonces À traiter et Favoris ;
- filtres 1/3/10/30 jours ;
- salaire min/max ;
- filtre Salaire précisé ;
- tri serveur meilleur match puis plus récent ;
- favori ;
- Pas intéressé avec empreinte anti-réimport ;
- ouverture de l’annonce source ;
- synchronisation France Travail + Hellowork + Indeed.

## APK
L’APK debug est compilé automatiquement par GitHub Actions à chaque push sur `main`.
